# Loiane Training Angular

Repositório com estudos práticos de Angular, contendo exemplos e exercícios sobre conceitos fundamentais da framework.

## Conteúdo

- Componentes
- Data binding
- Diretivas
- Roteamento
- Serviços e injeção de dependência
- Uso de bibliotecas externas
- Estrutura básica de projetos Angular

## Tecnologias

- Angular
- TypeScript
- Node.js
- Angular CLI

## Como usar

Cada pasta do repositório representa um módulo ou projeto de estudo. Para rodar um projeto localmente, entre na pasta correspondente e execute:

```bash
npm install
ng serve
```

## Objetivo

Registrar e organizar o aprendizado em Angular por meio de exemplos práticos e projetos pequenos.
